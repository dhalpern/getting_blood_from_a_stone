# getting_blood_from_a_stone
Code associated with the paper README for code associated with the paper "Getting Blood From a Stone: mproving Brain-Behavior Inferences Without Brain Data" by David J. Halpern Todd M. Gureckis

Figures 4, 5, 6 and S1, 2, 3 require first running the associated simulation code in the files that include "script" in their name.
Figures are all generated with the correspondingly labeled code.

Public data from HCP needed for generating figure S1 is included.
